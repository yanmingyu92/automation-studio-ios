DocKeeper Support

Troubleshooting

  • Document scanning requires a physical device with a supported camera. File import remains available when scanning is unavailable.
  • Enable notifications to receive warranty and renewal reminders.
  • For Paperless-ngx, use an HTTPS server URL and an API token with only the permissions required by the integration.

Purchases

Use Restore Purchases in the app with the Apple Account used for the original purchase. Subscription management and refunds are handled through your Apple Account.

Contact

Open a GitHub support issue and include the app version, iOS version, and steps to reproduce the problem. Do not include private reports, health data, documents, recordings, passwords, or API tokens.
